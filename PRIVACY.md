# Privacy Policy — Loop and Lore Channel Tools

Effective date: 2026-10-04
Contact: aero.guitarhero@gmail.com

## 1. Who we are and what this application is

Loop and Lore Channel Tools ("the Application") is a private desktop application operated by the owner of the YouTube channel "Loop and Lore" (the "Owner"). It runs only on the Owner's own computer and is used only by the Owner. It is not offered to, installed by, or accessible to any other person.

## 2. Use of YouTube API Services

The Application uses **YouTube API Services** (YouTube Data API v3 and YouTube Analytics API). By using the YouTube features of the Application, the Owner agrees to the [YouTube Terms of Service](https://www.youtube.com/t/terms). Google's handling of data is described in the [Google Privacy Policy](https://policies.google.com/privacy).

## 3. Information the Application accesses

Through the YouTube API Services, with the Owner's OAuth 2.0 authorization, the Application accesses:

- **The Owner's own channel data**: channel ID and title, the list of uploaded videos, and the ability to upload videos, set thumbnails and captions, and set privacy/publishing status.
- **The Owner's own channel analytics**: views, watch time, average view percentage, impressions and click-through rate, subscribers gained, and audience retention, for the Owner's own videos only.
- **Publicly available YouTube data**: video titles, descriptions, view counts, thumbnails, and public comments returned by search and video list endpoints, used for trend research.

The Application does **not** access any other YouTube user's private data, and it does not collect personal information from viewers or commenters beyond what the YouTube API returns as public data.

## 4. How information is stored and for how long

- OAuth tokens and the Owner's own channel analytics are stored **locally on the Owner's computer** and are used only to operate the Owner's channel.
- Publicly available YouTube data obtained for trend research is **refreshed or deleted within 30 days** of retrieval. Only aggregated, non-identifying statistics (for example, counts of frequently used phrases) are kept longer.
- No information obtained from YouTube API Services is sold, shared, transferred, or disclosed to any third party, and none is used for advertising or for building profiles of any person.
- The Application does not use YouTube API data to train or improve machine-learning models.

## 5. Cookies and tracking

The Application has no website front end for users and sets no cookies. It does not track anyone.

## 6. Revoking access and deleting data

- The Owner can revoke the Application's access to their Google account at any time at the [Google security settings page](https://security.google.com/settings/security/permissions). Revocation immediately stops all API access.
- Stored data can be deleted at any time by deleting the Application's local data folder. Public YouTube data is deleted automatically after 30 days as described above.
- Any person who believes the Application holds data about them may contact the address above; such data will be deleted within 7 days.

## 7. Changes to this policy

Changes will be posted on this page with a new effective date.
