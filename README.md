# Loop and Lore — Channel Tools

**Loop and Lore Channel Tools** is a private, single-user desktop application that the owner of the YouTube channel [Loop and Lore](https://www.youtube.com/@loopandlore-zzz) uses to manage that channel.

It is not a public product. There is no sign-up, no download for other users, and no third-party access.

## What the tool does

- Uploads videos produced by the channel owner to the channel as **private**, and sets their thumbnails and captions
- After the owner manually reviews each video, schedules it for publishing
- Reads the owner's own channel analytics (views, watch time, retention, click-through rate) to improve future videos
- Reads publicly available video metadata (titles, view counts, top comments) for trend research
